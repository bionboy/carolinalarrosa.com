# carolinalarrosa.com

Static website for `carolinalarrosa.com`, deployed with GitHub Pages.

## Local Preview

Open `index.html` in a browser, or serve the directory locally:

```sh
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deployment

Pushing to `main` deploys the site through the GitHub Pages workflow in `.github/workflows/pages.yml`.
